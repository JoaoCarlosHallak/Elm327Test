# ELM327 Test

Projeto de estudo e suporte para um possível projeto futuro.

Atualmente, o projeto consiste em uma aplicação Java capaz de se comunicar, através do console, com a porta serial de um dispositivo ELM327. A aplicação permite selecionar e configurar uma porta de comunicação, estabelecer a conexão e enviar comandos diretamente ao dispositivo, além de disponibilizar uma pequena lista de ajuda, baseada no modelo original do dispositivo, com os principais comandos do ELM327.

O objetivo é utilizar essa comunicação como base para, futuramente, desenvolver um sistema próprio de diagnóstico automotivo.

O projeto pode ser utilizado para se comunicar com qualquer porta COM disponível no computador, porém seu foco é totalmente voltado à comunicação com o ELM327 e ao desenvolvimento do futuro sistema de diagnóstico automotivo.
